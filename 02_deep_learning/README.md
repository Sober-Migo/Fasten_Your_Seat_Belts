## 🎯 Campaign log

| Campaign | Theme | Key encounters |
|----------|-------|----------------|
| **C1 — The First Descent to Deep** | Logistic regression → deep nets | **Boss:** Build a deep network from scratch. Binary classification, planar data, DNN applications. |
| **C2 — Tuning the Engine** | Optimization & regularization | **Boss:** Beat overfitting with init, regularization, gradient checking, and better optimizers. TensorFlow workflow debut. |
| **C3 — The Strategist** | ML project strategy | **Boss:** A 1-hour case-study gauntlet: orthogonalization, bias/variance, error analysis, data distribution shifts. |
| **C4 — The Eye** | Convolutional neural networks · vision | **Boss:** ResNet. Then object detection with **YOLO**, face recognition, neural style transfer. |
| **C5 — Memory** | Sequence models · language intro | **Boss:** Neural machine translation. Plus LSTM char-level LM, jazz improvisation, Emojify, trigger word detection. |

## ⚔️ Master boss — *"The Eye"*

The moment a network learned to see was the first time the work felt like building an intelligence rather than tuning a formula. ResNet skipped its own layers to win; YOLO redefined detection speed; style transfer proved networks learn representation, not just answers.
